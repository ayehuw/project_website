# Project

This repository contains a final project for the _Beginning Web Development_ course at the UW iSchool.

All the files in this repository contribute to building a personal website for Alice Yeh. 

The website has a total of 4 webpages (4 .html files)- home page which contains a brief introduction of the site owner; a data project page which showcases several projects; photography page, which highlights some photography work of the site owner; and a contact page.

There is a shared .css file (style.css) for all of the webpages defining most of the styling, while a few features use Bootstrap for styling.

The js folder contains 2 .js files for interactivity of the data and photo pages respectively. Interactivity for these two pages uses some jQuery and Bootstrap.
